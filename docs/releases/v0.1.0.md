# VPS Manager v0.1.0

VPS Manager brings Linux VPS management and Cloudflare Workers operations into a self-hosted web workspace for individuals and small teams. This release packages the existing functionality under a versioned source distribution, with English and Simplified Chinese documentation.

## Included capabilities

- Host inventory, tags, SSH host-key verification, and encrypted SSH credential storage.
- CPU, memory, load, and disk snapshots, plus predefined commands for common operational checks.
- Browser-based SSH terminals, parameterized runbook previews and execution, job cancellation, and audit records.
- Rule-based process anomaly scans and optional AI explanations and troubleshooting suggestions.
- Cloudflare Worker metadata, encrypted API tokens, JavaScript module versions, deployment plans, and rollback plans, with optional provider execution.
- PostgreSQL persistence for metadata and encrypted credentials, Redis readiness checks, and Vault Transit credential encryption.

## Getting started

Download and extract the source archive, then follow the Docker Compose instructions in the [English README](../../README.md#quick-start) or [简体中文 README](../../README.zh-CN.md#快速启动).

The web workspace opens at `http://127.0.0.1:3000/login`. Add a host, confirm its SSH fingerprint, save its SSH credentials, and request a runtime snapshot. Private-network targets, mutating runbooks, Cloudflare provider execution, and the remote AI gateway require the configuration described in the README.

The source distribution includes the Go services, web application, Compose configuration, migrations, documentation, and MIT license. Docker Compose downloads container images and installs dependencies during startup.
