# ADR-0003：凭据与 Connector 边界

## 决策

数据库保存信封加密后的凭据版本、密钥引用和非敏感元数据。加密上下文绑定 installation、对象、版本和类型，业务接口只传凭据引用，不提供明文读取接口。

Connector 是独立进程。Control API 请求使用 HMAC 覆盖方法、路径和正文，Connector 校验时间戳与 nonce。执行接口使用固定动作和结构化参数，不接受自由 Shell、代理配置或 SSH 转发。

SSH 使用前先探测并确认 host key；指纹变化后命令、扫描、快照与终端拒绝连接。开发模式使用 DevKMS 完成单次操作所需的解密。生产 Vault 适配器当前只实现 wrap，秘密交接未接通时相关执行接口不可用。
