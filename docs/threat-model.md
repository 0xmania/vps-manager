# Web VPS 管理平台威胁模型

> 范围：当前自托管单租户实现；公共 SaaS 不适用
> 关联：`architecture.md`、`permission-matrix.md`、`credential-lifecycle.md`

## 1. 安全目标

平台将身份、策略、密钥、执行和审计分开，限制单点失陷造成的多主机影响。

安全目标按优先级如下：

1. 防止未授权用户借平台访问 VPS、执行命令或发布 Worker。
2. 防止 SSH 私钥、Cloudflare Token、会话和终端票据泄漏或跨对象复用。
3. 防止资产地址、任务参数和 WebSocket 成为 SSRF、注入或横向移动通道。
4. 验证主机身份，host key 未确认或发生变化时拒绝连接。
5. 让高风险动作可追溯到用户、角色、目标、理由和结果。
6. 限制控制面、Connector、部署器或 AI 单点失陷后的攻击半径。
7. 在部分依赖不可用或结果未知时避免“误判成功”和危险重试。

本模型不承诺一次性异常扫描能证明主机安全，也不覆盖目标 VPS 内核已被完全控制后对采集结果的伪造。

## 2. 建模范围与假设

### 2.1 范围内

- 浏览器、Web UI、BFF、Control API，以及开发会话和 Ed25519 身份桥接。
- RBAC、PostgreSQL/内存存储、Redis 就绪检查与任务状态。
- SSH Connector、目标地址策略、host key、SSH 凭据、固定命令、Web SSH 和 Runbook。
- 开发环境 DevKMS 与生产环境 Vault wrap-only 适配器。
- Cloudflare Worker 元数据、版本、部署计划，以及开发环境 Provider 执行链路。
- 运行快照、规则扫描与可选 AI 分析网关。
- Compose 自托管配置、日志和恢复边界。

### 2.2 范围外

- 公共注册、多租户隔离、跨地域 HA 和计费。
- 生产 OIDC、重新认证、break-glass、独立构建器和远端审计服务。
- 云厂商账号、VPS 控制台和 Serial Console 本身的安全。
- VPS 上现有业务应用、操作系统补丁和用户自有 SSH 配置的完整审计。
- Cloudflare 平台自身的内部安全。
- 浏览器或管理员终端已被完全控制后的保密性。
- 国家级攻击者和硬件/固件供应链攻击。

### 2.3 部署假设

- 部署者负责宿主机、TLS 私钥、配置和备份介质。
- SSH 账号与 sudoers 由部署者配置；平台只提供固定命令目录和参数校验。
- Vault、身份桥接和网络范围通过部署配置指定。
- 私网 CIDR 只有显式配置后才可访问。
- 系统时钟必须可靠，否则会话、票据和审计时间无法准确判断。

## 3. 资产与数据分类

数据分类以 [data-classification.md](data-classification.md) 为准。关键资产包括 SSH 私钥、Cloudflare Token、会话与终端票据、终端内容、命令输出、主机地址、审计记录和备份。密文仍按秘密数据管理，因为它可与密钥服务权限组合后恢复明文。

## 4. 信任边界与数据流

| 边界 | 跨越的数据 | 主要威胁 | 核心控制 |
|---|---|---|---|
| Browser ↔ Web/API | Cookie、表单、WebSocket、输出 | XSS、CSRF、会话盗用、WS 劫持、秘密回显 | TLS、安全 Cookie、Origin、服务端授权、输出编码 |
| Web 身份桥接 ↔ Control API | 签名身份断言 | issuer 混淆、断言重放、身份伪造 | Ed25519 签名、固定 issuer/audience、jti、会话绑定和短时效 |
| API ↔ PostgreSQL | 业务元数据、密文、审计索引 | SQL 注入、IDOR、密文替换、备份泄漏 | 参数化查询、对象范围检查、加密上下文、最小 DB 身份 |
| Control API ↔ Redis | 就绪状态与适配器数据 | 未授权访问、状态伪造 | 认证、部署网络隔离和受控连接配置 |
| Control API ↔ Vault/DevKMS | 密文、上下文、wrap 请求 | 任意解密、上下文混淆、权限扩大 | 对象+版本绑定；生产仅启用 wrap，开发环境执行解密 |
| Connector ↔ VPS | SSH 握手、命令、PTY、输出 | MITM、恶意主机、横向移动、输出注入 | host key pinning、地址策略、最小账号、禁转发、超时/限流 |
| Control API ↔ Cloudflare Provider | 预构建模块、配置、Token、部署状态 | Token 越权、错误账号、重复发布 | Bearer Token 校验、账号绑定、模块校验和状态记录；生产执行链路默认不可用 |
| Scanner ↔ AI provider | 脱敏结构化发现项 | 提示注入、敏感泄漏、幻觉/越权建议 | allowlist 字段、内容隔离、固定 Schema、无工具权 |
| Control API ↔ 本地审计存储 | 结构化审计事件 | 篡改、丢失、日志注入 | 结构化编码、字段限制和持久化错误上报 |

## 5. 攻击者模型

考虑以下攻击者：

- 未登录的互联网攻击者，可访问公开 HTTP/WSS 入口。
- 已登录的低权限用户，试图越权到其他主机、凭据、任务或审计。
- 恶意或账号被盗的运维员，试图扩大目标、隐藏审计或导出秘密。
- 已被攻陷的目标 VPS，向 Connector 返回恶意输出、控制序列或异常大数据。
- 获得数据库、Redis、日志或备份副本的攻击者。
- 被注入恶意内容的进程名或发现项文本，试图影响 AI 解读。
- 被部分攻陷的控制面或 Connector。完全控制宿主机属于高残余风险，需通过部署隔离和平台外恢复降低影响。

## 6. 威胁与当前控制

`P0` 表示直接影响主机或账号控制权，`P1` 表示影响范围较小或依赖额外条件。

| ID | 风险 | 场景 | 当前控制 |
|---|---|---|---|
| `TM-AUTH-01` | P0 | 身份断言伪造、issuer 混淆或重放 | Ed25519 签名、固定 issuer/audience、jti、会话绑定和过期时间 |
| `TM-AUTH-02` | P0 | 会话固定或 Cookie 被长期复用 | 服务端会话、Cookie 属性、空闲与绝对过期、注销撤销 |
| `TM-AUTH-03` | P0 | 跨站请求发起变更 | 同源检查、JSON 内容类型和服务端授权 |
| `TM-AUTHZ-01` | P0 | 改写资源 ID 访问其他主机、任务或凭据 | 每次请求检查角色、权限和对象 scope |
| `TM-ASSET-01` | P0 | 借主机地址扫描本机、云元数据或未授权网段 | 地址规范化、DNS 解析后复检、CIDR 策略和端口限制 |
| `TM-SSH-01` | P0 | 首次连接 MITM 或 host key 变化 | host key pinning；未确认或变化时拒绝执行 |
| `TM-SSH-02` | P0 | Web SSH 被用作网络隧道 | Connector 不开放 Agent、TCP、X11、SFTP 或 SCP 转发 |
| `TM-CRED-01` | P0 | 私钥或 Token 进入响应、日志和任务参数 | 上传即加密、后续只传凭据引用、接口不回显秘密 |
| `TM-CRED-02` | P0 | 密文复制到其他凭据后仍可解密 | 加密上下文绑定 installation、credential、version 和 type |
| `TM-CRED-03` | P0 | 生产环境控制面直接解密凭据 | 生产适配器只提供 wrap；秘密交接未接通时执行接口不可用 |
| `TM-JOB-01` | P0 | 参数注入变成任意 Shell 命令 | 固定命令目录；枚举参数映射为固定字面量，不接受用户 Shell 文本 |
| `TM-JOB-02` | P0 | Connector 请求被篡改或重放 | HMAC 覆盖方法、路径和正文，并校验时间戳与 nonce |
| `TM-JOB-03` | P0 | 重复请求造成同一动作多次执行 | Job 状态机、幂等键和 Runbook 单进程执行账本 |
| `TM-OUT-01` | P0 | 恶意主机用超大输出或控制字符影响平台 | 输出字节上限、终端渲染隔离和结构化事件 |
| `TM-WS-01` | P0 | 跨站 WebSocket 或终端票据复用 | Origin 检查、短时单次票据和服务端 scope 校验 |
| `TM-CF-01` | P0 | Token 越权、账号错配或模块被替换 | Token 类型与账号绑定、预构建模块校验、目标版本记录 |
| `TM-CF-02` | P1 | Cloudflare 响应未知后重复发布 | 保存外部版本和错误分类；不自动重试 Provider 动作 |
| `TM-AUDIT-01` | P1 | 日志注入或审计记录丢失 | 结构化事件、字段长度限制和存储错误上报 |
| `TM-AI-01` | P1 | 主机数据中的提示注入影响分析 | 只发送结构化字段、固定输出 Schema、模型无工具权限、网关目标精确匹配 |
| `TM-AI-02` | P1 | 模型幻觉被当成执行指令 | 规则扫描结果独立存在；AI 只返回说明和建议，不直接执行 |
| `TM-BACKUP-01` | P1 | 备份泄漏密文或恢复材料 | 密文与密钥材料分离，备份访问由部署环境控制 |

## 7. 关键滥用路径

### 7.1 从低权限账号到 VPS Shell

攻击链：窃取只读用户会话 → 枚举 host ID → 直接请求终端票据 → 复用其他用户票据 → 建立 WebSocket。

阻断点：对象 scope、`terminal.open` 权限、票据绑定与单次消费、WebSocket 服务端授权和 host key 状态。

### 7.2 从 Host 地址到控制面横向移动

攻击链：录入 `169.254.169.254`、loopback、内部数据库地址或可 DNS rebinding 的域名 → 触发连接测试/SSH → 访问元数据或内部服务。

阻断点：API 规范化和初筛、Connector DNS 解析后复检、获准端口、目标 CIDR allowlist、Connector 网络出口策略。

### 7.3 从恶意参数到 root 命令

攻击链：在模板参数中输入 Shell 元字符、换行、前导 flag 或路径穿越 → 模板拼接 `sh -c` → 借 sudo 执行任意命令。

阻断点：服务端固定命令、参数 allowlist、固定字面量映射和部署侧 sudoers 配置。

### 7.4 从数据库备份到所有 VPS

攻击链：取得数据库/备份 → 提取全部 SSH 私钥密文 → 交换 credential ID 或离线解密 → 批量接管 VPS。

阻断点：不存明文、对象/版本/type 加密上下文、密钥材料分离和外部凭据轮换。

## 8. 安全失败策略

| 故障 | 默认行为 | 说明 |
|---|---|---|
| 身份桥接不可用 | 不创建新会话 | 已建立会话按原过期时间处理 |
| Vault/DevKMS 不可用 | 凭据写入或开发执行返回错误 | 元数据读取不依赖解密 |
| Redis 不可用 | Redis 就绪检查和相关适配器操作不可用 | Connector 不直接消费 Redis 队列 |
| Connector 不可用 | WebSSH、Runbook 和生产 host key 探测不可用 | 开发模式的固定 SSH 操作使用进程内 runner |
| PostgreSQL 不可用 | 需要持久化状态或审计的动作返回错误 | 不用缓存角色替代授权事实 |
| host key 记录异常 | SSH 路径拒绝连接 | 需要重新确认新的 host key |
| 权限状态读取失败 | 拒绝执行 | 不猜测用户权限 |
| Cloudflare API 超时 | 记录 timeout 失败 | Provider 动作不自动重试 |
| AI 不可用/输出无效 | 返回规则结果，不返回 AI 结论 | 核心扫描不受影响 |

## 9. 残余风险与风险接受

| 风险 | 当前限制 | 必要处置 |
|---|---|---|
| 自托管宿主机被 root 控制 | 宿主可读取进程内秘密或篡改容器 | 主机加固、独立密钥材料和平台外备份 |
| 目标 VPS 完全失陷 | 可伪造命令输出、快照和扫描证据 | 明确报告边界；必要时引入持续 Agent/外部遥测；不自动处置 |
| Web SSH 内容含业务秘密 | 内容会经过 Connector 内存 | 限制终端权限与会话时长，按部署要求管理日志 |
| 长期 SSH 私钥 | 平台失陷时攻击半径较大 | 缩小账号权限、定期轮换，并在不需要时停用凭据 |
| 管理私网 VPS | Connector 必须访问高价值内网 | 只开放明确配置的 CIDR，并隔离 Connector 网络 |
| 单租户并非租户隔离 | 不能承载互不信任客户 | 当前仅用于单租户自托管环境 |

风险接受记录应包含威胁 ID、受影响资产、理由、补偿措施、责任人和复核时间。

## 10. 当前未接通的边界

- 生产 OIDC、重新认证和 break-glass 流程未实现。
- 生产凭据秘密交接未接通，因此需要解密的 SSH、Web SSH、Runbook 和 Cloudflare Provider 执行不可用。
- 独立 Worker 构建器、远端审计存储和多节点调度未接通。
- 开发会话、任务调度和部分恢复状态仍是进程内实现，不提供高可用保证。
